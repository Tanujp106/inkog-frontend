# 404 Final Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the 404 logo/header, add a gentle visual ball bounce while idle or waiting, and retain destroyed bricks as faint ghost pixels.

**Architecture:** Keep game state and physics unchanged. Header removal is limited to the App Router shell and scoped CSS; bounce timing lives in a pure rendering helper and only affects canvas draw coordinates; ghost bricks are a separate no-glow canvas pass before active bricks.

**Tech Stack:** Next.js App Router, React, TypeScript, HTML canvas, Node test runner, CSS.

## Global Constraints

- The Breakout arena begins at viewport `y: 0` and occupies the full `100dvh`.
- Keep the screen-reader-only `404 page not found` heading and both in-game home recovery links.
- Idle and waiting bounce is an 8-pixel hop on a 1,200ms loop and is disabled for reduced motion.
- Bounce is visual only and must not mutate ball position, velocity, collisions, sounds, or launch behavior.
- Destroyed bricks use the current accent at 8% opacity with no glow and remain visible under cleared-state confetti.
- Do not change physics, controls, sounds, lives, speed, confetti behavior, shader props, routes, dependencies, or brick geometry.
- Reuse the existing `127.0.0.1:3000` listener for browser verification; start it only if no listener exists.

- [ ] **Step 3: Implement the pure bounce helper**

Create `lib/not-found-breakout-render.mjs`:

```js
const BOUNCE_DURATION_MS = 1200;
const BOUNCE_HEIGHT = 8;

export function getBreakoutIdleBallOffset(elapsedMs, mode, prefersReducedMotion) {
  if (prefersReducedMotion || (mode !== "idle" && mode !== "waiting")) return 0;
  const safeElapsed = Number.isFinite(elapsedMs) ? Math.max(0, elapsedMs) : 0;
  const progress = (safeElapsed % BOUNCE_DURATION_MS) / BOUNCE_DURATION_MS;
  return -BOUNCE_HEIGHT * Math.sin(Math.PI * progress) ** 2;
}
```
